# Команди ES — тренажер команд інструктора іспанською

Вебзастосунок у стилі Duolingo для інструкторів FPV: 7 розділів, ~130 команд і фраз з українською, іспанською та вимовою кирилицею. Працює на Android, iPhone і Windows, встановлюється на головний екран, після першого відкриття працює без інтернету.

## Як опублікувати на GitHub Pages (безкоштовно)

1. Зареєструйтеся або увійдіть на github.com.
2. Створіть новий репозиторій: **New repository** → назва, наприклад, `komandy-es` → **Public** → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file** (або **Add file → Upload files**) і перетягніть **увесь вміст папки `komandy-es`** з архіву (файли та папки `icons` і `audio`). Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**, гілку **main**, папку **/(root)** → **Save**.
5. За 1–2 хвилини з'явиться адреса на кшталт `https://<ваш-логін>.github.io/komandy-es/`. Її й розсилайте інструкторам.

## Як встановити на пристрій

- **Android (Chrome):** відкрити адресу → меню ⋮ → «Додати на головний екран» / «Встановити застосунок».
- **iPhone (Safari):** відкрити адресу → «Поділитися» → «На Початковий екран».
- **Windows (Edge або Chrome):** відкрити адресу → значок встановлення в адресному рядку.

## Звук

Порядок, у якому застосунок шукає звук для фрази:

1. Записи носія, зроблені на цьому пристрої (Налаштування → Запис голосу носія).
2. Вбудовані аудіофайли в папці `audio/` (з'являться, коли записи носія буде вбудовано для всіх).
3. Синтезований іспанський голос пристрою.

## Оновлення

Після зміни файлів збільште номер версії в `sw.js` (`komandy-es-v1` → `komandy-es-v2`), інакше встановлені копії можуть показувати стару версію.

Фрази живуть у `index.html`, у масиві `U` на початку скрипту: `[українською, іспанською, вимова]`, наголос позначено `+` після голосної.
